    How it works

    Deobfuscators

    unravel ★ runs the full pipeline — sandboxed runtime string-array decode, control-flow un-flattening, opaque-predicate resolution, anti-debug stripping, dead code & dead variable removal, then renaming. so specialises in string tables (base64/RC4/rotation), scrambled rebuilds flattened switch state machines, binder kills self-defending wrappers & unwraps literal eval(), TASLA is the aggressive multi-pass cleaner.

    Decompiler mode

    No deobfuscation at all — just structural recovery for people who only need readable output: pretty-printing, declaration splitting, brace restoration and local-variable renaming. Perfect for minified bundles that were never obfuscated.

    Universal dumper

    Works against every JS obfuscator because it doesn't try to symbolically undo them. The script is instrumented (eval / new Function / string args / global probes) and executed inside a sandboxed iframe with loop guards and a watchdog — then unravel dumps every decoded string, eval payload and environment probe as a clean report.

    Simplify toggle

    On = aggressive extra passes: constant-driven branch pruning, var→const promotion, computed member normalisation, unreferenced function/variable removal and heuristic renaming (_0x3f2a → fn2, a1 → handler). Off = minimal, semantics-preserving output.

    Everything runs locally in your browser — nothing is uploaded. Inspired by webcrack. For research on code you have the right to analyse.
